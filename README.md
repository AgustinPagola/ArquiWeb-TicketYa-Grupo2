# TicketYa

Plataforma de venta de entradas basada en microservicios con Spring Boot.

## Estructura
- `catalogo-service`: eventos, lugares, sectores y búsqueda
- `ventas-service`: reservas, compras, entradas con QR y devoluciones
- `api-gateway`: punto de entrada único
- `docs`: diseño y diagramas
- `postman`: colección de requests
